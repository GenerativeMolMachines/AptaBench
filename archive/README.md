# Archive

This folder holds **non-canonical** copies of notebook exports and other files that are **not** required to use the Hugging Face dataset or to install the `src` package.

- **`notebook_exports/`** — legacy CSV files produced by earlier notebook runs (superseded by canonical tables under `artifacts/ml/` and `artifacts/dl/`).

Large embedding caches and Optuna databases under `notebooks/notebooks/` are **not** version-controlled; regenerate them by running the benchmarking notebooks or ignore those cells for a lightweight review.
